                    FreeCodeCamp Survey Form

This project is a  survey form inspired by the FreeCodeCamp Responsive Web Design project.
It collects basic user information and feedback that could help improve an online learning platform.

         Features

Collects user name, email, and age

Dropdown menus for selecting:

Current role

Radio buttons for recommendation choice

Checkboxes for improvement suggestions

Text area for comments and feedback

Styled using CSS
